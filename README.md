# Data-Professionals-Survey – Power BI Dashboard
 An interactive Power BI dashboard analyzing global survey responses from data professionals. Uncovers key industry insights across salaries, job roles, preferred programming languages, using Power Query and DAX.

Tools & Technologies

Power BI: Dashboard development and data visualization.

Power Query: Data cleaning and transformation.

DAX: Calculated measures and analytical metrics.

Power BI Data Modeling: Organizing data for effective analysis.

Project Workflow

Data Loading: Imported the data professionals survey dataset into Power BI.

Data Cleaning: Used Power Query to handle missing values, inconsistent entries, and data formatting.

Data Transformation: Prepared and structured the dataset for analysis.

Data Modeling: Organized the data to support interactive reporting.

DAX Calculations: Created measures and calculated metrics to support analysis.

Dashboard Development: Designed an interactive dashboard to explore survey results and industry trends.

Dashboard

The Power BI dashboard explores several key areas:

Average salaries across different data job roles.

Distribution of respondents by job title.

Preferred programming languages among data professionals.

Salary comparisons across professional roles.

Country-based distribution of survey respondents.

Career satisfaction and work-related insights.

Key Results

Explored salary differences across data-related job roles.

Identified popular programming languages among data professionals.

Analyzed the global distribution of survey respondents.

Examined career satisfaction and industry trends.

Presented survey findings through interactive Power BI visualizations.
